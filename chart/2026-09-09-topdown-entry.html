Top-down Entry
상위 추세와 하위 Trigger를 하나의 매매계획으로 연결하기

좋은 진입은 하위 시간축에서 예쁘게 보이는 캔들 하나가 아니라, 상위 시간축의 방향·위치와 하위 시간축의 Trigger가 같은 논리를 가질 때 만들어집니다.

Entry Design25분난이도 ★★★☆☆
교육용 합성 차트Context → Setup → Trigger

1. Context

매매의 배경입니다. 주봉·일봉의 추세, 주요 지지·저항, 이동평균선 배열을 확인합니다. 상위 TF가 상승 추세라면 하위 TF의 눌림 매수가 논리적으로 더 자연스럽습니다.

2. Setup

가격이 어디까지 조정되었는지 봅니다. 이전 돌파선, MA20/60, 지지 Zone, 갭 상단 등이 겹치는지 확인합니다.

3. Trigger

실제 주문을 고려하게 만드는 조건입니다. 예: 60분 Swing High 돌파, 상승 장악형 고가 돌파, 거래량 증가, MA20 재돌파.

4. Invalidation

진입 논리가 틀렸음을 인정할 가격입니다. 하위 TF의 작은 잡음이 아니라 Setup이 무너지는 가격대를 기준으로 잡습니다.

5. 실전 체크

  • 상위 추세와 같은 방향인가?
  • 가격이 의미 있는 Zone에 있는가?
  • Trigger가 숫자로 정의되어 있는가?
  • 손절 가격이 진입 전에 정해졌는가?
  • 리스크 대비 목표수익이 충분한가?
좋은 진입: 싸 보여서 사는 것이 아니라, Context와 Setup이 준비된 상태에서 Trigger가 발생했을 때 실행합니다.

복습 퀴즈

Q1. Context란?

상위 시간축의 추세·위치 배경입니다.

Q2. Trigger란?

실제 진입을 고려하게 만드는 객관적 조건입니다.

Q3. 손절은 언제 정하나?

진입 전에 정합니다.

Q4. 좋은 눌림의 핵심?

상위 추세와 의미 있는 지지 Zone의 정렬입니다.

Q5. 순서는?

Context → Setup → Trigger → Invalidation.
