# Sector Analysis

Static GitHub Pages archive for sector and company research.

## Required fields for every report
- 분석일 (analysis date)
- 사용한 시장 데이터 기준일 (when market prices are referenced)
- 핵심 근거/출처 (official IR / SEC preferred)
- 직접 수혜 vs 인접 수혜 구분
- 리스크 / invalidation / valuation note

## Structure
- `sector/index.html` — sector hub
- `sector/<sector>/index.html` — sector overview
- `sector/<sector>/<report>.html` — individual research report

New sectors and company reports should follow the same structure so the archive can expand without changing the main Hub layout.
