# Daily English — 새 채팅에서 쓰는 간편 실행 프롬프트

이 문서는 새 채팅/Work에서 **긴 설명을 붙이지 않고 기존 요구사항을 호출하기 위한 단축 문구 모음**이다.

## 1. 권장 한 줄 프롬프트 (차주)

> GitHub `shinyab-v2/shinyab-v2.github.io`의 `requirements/daily-english/README.md` 요구사항에 따라 **차주 Daily English**를 B1~B2와 A1~A2 각각 7일치 작성·검증하고 `main`에 반영하여 GitHub Pages 배포까지 확인해줘.

이 한 줄은 학습 자료 14일분 작성(두 수준), 문법·예문·이디엄·단락별 접힌 번역·단어장용 어휘·퀴즈·말하기·Role play·아카이브 연결·최종 배포 검증을 모두 포함한다.

## 2. 더 짧게

> GitHub의 Daily English 주간 제작 요구사항을 참고하여 차주 자료를 작성하고 배포해줘. 저장소: `shinyab-v2/shinyab-v2.github.io`

새 채팅은 이전 대화 내용을 모를 수 있으므로 **최소한 저장소 이름 또는 요구사항 문서 URL을 포함**한다.

## 3. 다른 요청

- 금주: "GitHub `shinyab-v2/shinyab-v2.github.io`의 Daily English 요구사항대로 **금주** B1~B2·A1~A2 자료를 작성·배포해줘."
- 날짜 지정: "동일 요구사항대로 **2026-11-02~2026-11-08** B1~B2·A1~A2 Daily English를 작성·배포해줘." (날짜는 필요할 때 수정)
- 품질만 재점검: "동일 요구사항대로 **최근 주간 Daily English의 14일 완전성, 문법·퀴즈·번역 품질, GitHub Pages 연결**을 검증해줘. 수정은 검증 결과를 보고 진행해줘."

## 4. 실행자가 따라야 할 절차

1. 먼저 이 저장소의 최신 `main`과 [상세 요구사항](./README.md), 기존 `english/`·`student-english/` 사이트 코드 및 정상 완료된 최신 주간 JSON을 직접 확인한다.
2. '차주'는 실행일의 **Asia/Kuala_Lumpur 월요일~일요일** 기준으로 다음 주의 정확한 날짜를 계산한다.
3. B1–B2와 A1–A2 각각 7일을 **콘텐츠 품질 및 고정 구조 기준을 모두 만족**하도록 작성한다.
4. 성인은 주간 JSON 및 `english/current-week-loader.js`, 학생은 주간 JSON 및 `student-english/data/week.json`을 반드시 일치시킨다. 기존 아카이브·단어장·Voice 기능을 유지한다.
5. JSON 수량/문법/퀴즈/단락별 번역 검증 후 **main 커밋 및 GitHub Pages 배포 결과**를 확인한다. 실패하거나 접근하지 못한 단계는 숨기지 않는다.
6. 최종 답변에는 기간별 2개 사이트 링크, 날짜별 학습 주제, 생성/검증 현황, 커밋 SHA를 기재한다.

**중요:** 이 문서는 긴 요구사항을 축약한 진입점일 뿐, [README.md](./README.md)의 검증 조건을 완화하지 않는다.
