1ST CONDITIONAL · IF I DO

1조건문
“정말 일어날 수도 있어”

말하는 사람이 미래의 상황을 가능한 일로 보고, 그 조건이 성립하면 어떤 결과가 생길지 말할 때 씁니다.

01

기본 구조

IF-CLAUSEif + present
→
MAIN CLAUSEwill + verb
If it rains, I’ll stay home.
비가 오면 나는 집에 있을 거야.
비가 올 가능성을 열어 두고 있음.
If we hurry, we’ll catch the bus.
서두르면 버스를 탈 수 있을 거야.
서두를지 여부가 실제 결과와 연결됨.
핵심: 미래를 말하지만 if절에서는 보통 현재형을 씁니다.
02

왜 if절에 will을 안 쓰나요?

영어에서는 미래의 조건을 나타내는 if절에 보통 현재형을 씁니다. 교재 Unit 25의 핵심도 바로 이 점입니다.

× If it will rain this evening, I won’t go out.
○ If it rains this evening, I won’t go out.
× If we will not hurry, we’ll be late.
○ If we don’t hurry, we’ll be late.

여기서 rains / don’t hurry는 문법 형태는 현재지만, 의미는 미래 조건입니다.

03

주절에는 will만 가능한가요?

아닙니다. 조건이 성립했을 때의 결과·가능성·허가·명령 등에 따라 다른 표현도 올 수 있습니다.

주절 형태예문느낌
willIf you call me, I’ll help you.미래 결과
canIf it stops raining, we can go out.가능/능력
may / mightIf she comes, we might eat outside.가능성
명령문If you see Mina, tell her to call me.조건부 지시
04

if와 when은 어떻게 달라요?

If I go out, I’ll get some bread.
나갈지 아닐지 아직 확실하지 않음.
When I go out, I’ll get some bread.
나가는 것은 확실하고, 그때 빵을 살 것.
교재의 구분: if는 일어날 수도/안 일어날 수도 있는 일, when은 일어날 것이 확실한 일에 사용합니다.
05

1조건문과 2조건문 비교

If you find my watch, can you call me?
시계를 실제로 찾을 가능성이 있음.
If you found a wallet in the street, what would you do?
길에서 지갑을 줍는 상황을 상상함.

교재 Unit 38은 if I find와 if I found를 나란히 비교해, 가능성의 거리 차이를 보여 줍니다.

06

짧은 연습

1. If it ___ tomorrow, we’ll stay home. (rain)

rains. 미래 조건이지만 if절에는 현재형.

2. Hurry up! If we ___, we’ll be late. (not hurry)

don’t hurry. if절의 현재형 부정.

3. I’m definitely going out later. ___ I go out, I’ll buy milk. (If / When)

When. 나가는 일이 확실하다고 이미 말했기 때문입니다.

교재 연결
