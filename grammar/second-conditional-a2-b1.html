2ND CONDITIONAL · IF I DID

2조건문
“지금 사실은 그렇지 않지만…”

현재 또는 미래 상황을 상상하거나, 실제로 일어날 가능성이 낮다고 보거나, 현재 사실과 다른 상황을 가정할 때 사용합니다.

01

기본 구조

IF-CLAUSEif + past
→
MAIN CLAUSEwould + verb
If I had more time, I would travel more.
시간이 더 있다면 여행을 더 많이 할 텐데.
실제: 지금 시간이 충분하지 않음.
If I knew his number, I’d call him.
그의 번호를 안다면 전화할 텐데.
실제: 번호를 모름.
가장 중요한 포인트: 여기서 had / knew는 과거 형태지만 문장의 의미는 현재일 수 있습니다.
02

왜 past를 쓰는데 현재 의미인가요?

교재 Unit 39는 상상하는 상황에서 if + past를 사용하지만, 그 의미는 과거가 아니라고 설명합니다. 이 past는 시간보다 현실과의 거리를 나타내는 역할을 합니다.

If I had more money, I’d buy that car.
지금 돈이 더 있다면.
If she lived nearer, we’d see her more often.
지금은 멀리 살지만, 가까이 산다면.
생각법: “past = 어제”로만 생각하지 말고, 조건문에서는 현실에서 한 걸음 떨어진 가정일 수 있다고 이해하세요.
03

was와 were

if절에서 were를 사용할 수 있습니다. 특히 If I were you는 매우 흔한 표현입니다.

If I were you, I wouldn’t buy it.
내가 너라면 그걸 사지 않을 거야.
If it weren’t so cold, we could eat outside.
이렇게 춥지만 않다면 밖에서 먹을 수 있을 텐데.

교재는 were 대신 was도 가능하다고 설명합니다. 따라서 If I were you와 If I was you 모두 가능하지만, 학습 단계에서는 If I were you를 대표 표현으로 익히면 좋습니다.

04

would / could / might의 차이

표현예문뜻
wouldIf I won, I would buy a house.그 상황이면 그렇게 할 것
couldIf it stopped raining, we could go out.그렇게 할 수 있을 것
mightIf I won, I might buy a house.아마 그럴 수도 있음
05

if절에 would를 쓰지 않는 기본 규칙

× If I would know his number, I would call him.
○ If I knew his number, I would call him.
× If I would be rich, I would travel a lot.
○ If I were rich, I would travel a lot.

교재 Unit 39도 일반적으로 if … would를 쓰지 않고, would는 다른 절에 둔다고 설명합니다.

06

1조건문과 의미 비교

If we take the bus, it will be cheaper.
버스를 탈 가능성이 실제로 열려 있음.
If we took the bus, it would be cheaper.
버스를 탈 계획이 아니거나, 가정으로 이야기함.

형태가 바뀌면 단순한 시제 변화가 아니라 화자의 태도가 바뀝니다.

07

짧은 연습

1. If I ___ his number, I would phone him. (know)

knew. 현재 번호를 모르기 때문에 현실과 다른 가정.

2. If I ___ you, I wouldn’t wait. (be)

were가 대표적인 형태입니다. 교재는 was도 가능하다고 설명합니다.

3. If it stopped raining, we ___ go out. “갈 수 있을 텐데”에 맞는 말은?

could. would be able to의 의미.
