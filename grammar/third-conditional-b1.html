3RD CONDITIONAL · IF I HAD DONE

3조건문
“그때 그랬더라면…”

이미 끝난 과거의 사실을 바꿀 수는 없지만, 그때 상황이 달랐다면 결과도 달랐을 것이라고 상상할 때 사용합니다. 후회, 아쉬움, 원인·결과를 되돌아볼 때 매우 자주 쓰입니다.

01

기본 구조

IF-CLAUSEif + had + p.p.
→
MAIN CLAUSEwould have + p.p.
If I had known, I would have gone.
알았더라면 갔을 텐데.
실제: 몰랐고, 가지 않았음.
If I had seen you, I would have said hello.
너를 봤더라면 인사했을 텐데.
실제: 보지 못했고, 인사하지 못함.
3조건문의 핵심: 문장 속 두 사건 모두 이미 지나간 과거입니다. if절은 과거완료, 결과절은 would have + p.p.
02

문장을 “실제 사실”로 뒤집어 보세요

3조건문실제로 일어난 일
If I had known, I would have gone.I didn’t know, so I didn’t go.
If they hadn’t been tired, they would have gone out.They were tired, so they didn’t go out.
If I’d had a camera, I would have taken pictures.I didn’t have a camera, so I didn’t take pictures.
학습법: 3조건문을 보면 항상 “실제 사실은 반대였구나”라고 역으로 해석해 보세요.
03

had had가 왜 나와요?

have의 과거분사도 had이기 때문에 과거완료는 had had가 됩니다.

If I had had a camera, I would have taken pictures.
카메라가 있었더라면 사진을 찍었을 텐데.
첫 had = 과거완료 조동사 / 두 번째 had = have의 과거분사

처음에는 어색해 보여도 구조는 규칙적입니다: had + p.p. → have의 p.p.가 had이므로 had had.

04

’d는 had일까요, would일까요?

If I’d seen you, ...
I’d seen = I had seen
... I’d have said hello.
I’d have said = I would have said
구별법: ’d 뒤에 바로 p.p.가 오면 had인 경우가 많고, ’d 뒤에 have + p.p.가 오면 would인 구조입니다.
05

if절에 would have를 쓰지 않는 기본 규칙

× If I would have seen you, I would have said hello.
○ If I had seen you, I would have said hello.

교재 Unit 40도 이 오류를 직접 지적합니다. 조건을 나타내는 if절에는 had + p.p., 결과절에는 would have + p.p.를 둡니다.

06

would have / could have / might have

표현예문의미
would haveWe would have gone out.그랬다면 나갔을 것
could haveWe could have gone out.그랬다면 나갈 수 있었을 것
might haveWe might have gone out.그랬다면 어쩌면 나갔을 수도 있음
07

2조건문과 3조건문 비교

If I was/were hungry, I would eat something.
지금 배고프다면 먹을 텐데. → 현재 가정
If I had been hungry, I would have eaten something.
그때 배고팠더라면 먹었을 텐데. → 과거 반대 가정
08

과거 조건 + 현재 결과도 가능해요

교재 Unit 40은 다음과 같은 형태도 비교합니다.

If I’d gone to the party last night, I would be tired now.
어젯밤 파티에 갔더라면 지금 피곤할 텐데.
조건 = 과거 / 결과 = 현재
If I’d gone to the party, I would have met lots of people.
파티에 갔더라면 많은 사람을 만났을 텐데.
조건 = 과거 / 결과 = 과거

즉, 조건문은 단순 공식보다 각 절이 어느 시간을 가리키는지 이해하는 것이 중요합니다.

09

짧은 연습

1. If I ___ you, I would have said hello. (see)

had seen. 과거에 보지 못한 상황의 반대 가정.

2. If they hadn’t been so tired, they ___ out. (go)

would have gone. 과거의 결과를 반대로 상상.

3. If I’d had my phone, I ___ you. “전화할 수 있었을 텐데”에 맞는 표현은?

could have called. 가능/능력을 강조합니다.

교재 연결

English Grammar in Use Unit 40의 if I had known / would have done, ’d = had/would 구별, would/could/might have, 과거 조건과 현재 결과의 비교를 중심으로 구성했습니다.
