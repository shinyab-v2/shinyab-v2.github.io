A2 → B1 · CONDITIONALS

조건문 1·2·3
시간보다 “현실과의 거리” 보기

조건문을 외울 때 가장 중요한 것은 단순히 시제 이름을 암기하는 것이 아니라, 말하는 사람이 그 상황을 가능한 미래로 보는지, 가정·상상으로 보는지, 또는 이미 지나가 바꿀 수 없는 과거로 보는지 구별하는 것입니다.

교재 기준: English Grammar in Use, 5th Edition은 “First / Second / Third Conditional”이라는 번호보다 if I do / if I did / if I had known이라는 실제 형태로 설명합니다. 이 페이지에서는 학습 편의를 위해 흔히 쓰는 1·2·3 조건문 이름을 함께 표시합니다.
01

먼저 세 문장을 비교하세요

1ST CONDITIONALIf it rains, I’ll stay home.

비가 올 수도 있다. 미래의 실제 가능성을 열어 둔다.

2ND CONDITIONALIf I had more time, I would travel.

지금은 시간이 별로 없다. 현실과 거리를 둔 가정이다.

3RD CONDITIONALIf I had known, I would have gone.

그때는 몰랐다. 이미 끝난 과거를 반대로 상상한다.

한 줄 기억: 1조건문 = 가능성, 2조건문 = 현재/미래의 가정, 3조건문 = 과거의 반대 가정.
02

형태 한눈에 보기

구분if절주절핵심 의미시간 중심
1조건문if + presentwill / can / may + 동사원형 등실제로 일어날 가능성이 있음주로 미래
2조건문if + pastwould / could / might + 동사원형현실과 거리를 둔 가정·상상현재 또는 미래 의미
3조건문if + had + p.p.would / could / might have + p.p.이미 끝난 과거를 반대로 상상과거
중요: 2조건문의 if + past는 “과거 이야기”라는 뜻이 아닐 수 있습니다. 교재는 형태는 past지만 의미는 present일 수 있다고 명확히 설명합니다.
03

시간선으로 이해하기

PAST이미 지나간 시간
NOW현재
FUTURE앞으로 가능한 일

1조건문은 미래의 가능성을 말하지만 if절에는 보통 미래형 will을 쓰지 않고 현재형을 씁니다.

PAST FORM형태는 과거
NOW / FUTURE의미는 현재·미래 가정
REALITY현실과 거리

2조건문의 past는 “시간상 과거”보다 현실과의 거리를 나타내는 데 중요합니다.

PAST실제 사건은 이미 끝남
NOW지금은 바꿀 수 없음
COUNTERFACT과거를 반대로 상상

3조건문은 과거에 실제로 일어나지 않은 일을 가정합니다.

04

가장 자주 틀리는 규칙

if절에 would를 바로 넣지 마세요.
× If it will rain, I’ll stay home. → ○ If it rains, I’ll stay home.
× If I would have more time, I would travel. → ○ If I had more time, I would travel.
× If I would have known, I would have gone. → ○ If I had known, I would have gone.

교재도 Unit 38~40에서 would는 보통 if절이 아니라 다른 절에 둔다고 반복해서 설명합니다.
