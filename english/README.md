# Daily English 제작 지침

이 디렉터리의 주간 콘텐츠는 단순 HTML 페이지 목록이 아니라 `week-YYYY-MM-DD/week.json`에 저장된 수업 데이터와 기존 렌더러가 함께 구성한다.

- 성인용 B1–B2: `english/`, `english/current-week-loader.js`에서 주간 JSON 로딩
- 학생용 A1–A2: `student-english/`, `student-english/data/week.json` 누적 이력을 함께 갱신해야 함
- **정식 주간 제작 요구사항:** [requirements/daily-english/README.md](../requirements/daily-english/README.md)
- **새 채팅용 짧은 프롬프트:** [requirements/daily-english/QUICK_PROMPT.md](../requirements/daily-english/QUICK_PROMPT.md)

새 주간 학습 자료를 제작하기 전에는 위 명세와 최신 GitHub `main`을 반드시 읽고, 2개 레벨 각 7일치의 완성 여부 및 Pages 배포를 검증한다.
