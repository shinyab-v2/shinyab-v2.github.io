Ultrasound AI Error Analysis

평균 metric 뒤에 숨은 실패 패턴을 데이터·label·architecture·optimization·domain 관점으로 분해합니다.

1. Error taxonomy

FN/FP를 단순 목록으로 보지 말고 small lesion, low contrast, shadow, artifact, boundary ambiguity, device/site, annotation disagreement 등 재현 가능한 category로 분류합니다.

2. 원인 계층

Data → Label → Preprocess/Augmentation → Architecture → Loss/Assignment → Optimization → Postprocess 순으로 가설을 세웁니다. 한 번에 여러 요소를 바꾸면 원인을 알 수 없습니다.

3. Slice 만들기

errors = df[df.correct == False]
errors.groupby(["lesion_size","device","artifact"]).size()

빈도가 높은 slice와 임상적으로 중요한 slice를 분리합니다.

4. Gradient/feature 연결

small lesion FN이 많다면 P3 feature activation, positive assignment, regression gradient를 함께 추적합니다. #11 gradient debugging과 #17 detection pipeline을 실제 failure에 연결하는 단계입니다.

5. 실험 원칙

가설 하나당 변경 하나를 우선합니다. 예: P2 추가, input resolution 증가, small-object oversampling을 동시에 하지 말고 각각 비교합니다.
