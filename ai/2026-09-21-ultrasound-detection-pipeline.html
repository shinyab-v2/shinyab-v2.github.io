Ultrasound Detection Pipeline

이론에서 프로젝트로 전환합니다. 초음파 입력부터 Backbone–FPN/PAN–Head–NMS–임상 평가까지 전체 detection system을 Tensor 관점으로 설계합니다.

1. 문제를 먼저 정의한다

모델보다 먼저 label과 clinical endpoint를 정의합니다. 한 영상에 병변이 하나인지 여러 개인지, box가 lesion 전체 경계인지 중심 영역인지, negative frame이 얼마나 있는지에 따라 학습 문제 자체가 달라집니다.

2. Tensor pipeline

x        [B,1,640,640]
stem     [B,64,320,320]
C3       [B,256,80,80]
C4       [B,512,40,40]
C5       [B,1024,20,20]
FPN/PAN  P3/P4/P5
Head     multi-scale box + class logits

20 px 병변은 stride 32 feature에서 1 cell보다 작아질 수 있습니다. 그래서 전체 mAP보다 small-lesion subgroup과 P3/P2 보존 여부가 중요합니다.

3. 1-channel 입력

ImageNet pretrained RGB backbone을 사용할 때 첫 Conv를 1-channel로 바꾸거나 grayscale을 3-channel로 복제할 수 있습니다. 구조 변경 시 pretrained weight를 평균하여 초기화하는 방법도 실험 대상으로 둡니다.

w_rgb = model.conv1.weight.data
model.conv1 = nn.Conv2d(1, 64, 7, 2, 3, bias=False)
model.conv1.weight.data.copy_(w_rgb.mean(dim=1, keepdim=True))

4. FPN/PAN 실전 관점

FPN은 deep semantic feature를 high-resolution feature로 전달하고, PAN은 localization-rich feature를 다시 bottom-up으로 전달합니다. 초음파의 작은 저에코 병변이나 얇은 경계에서는 P3가 특히 중요할 수 있습니다.

5. 평가 설계

mAP 하나로 끝내지 말고 lesion-level sensitivity, FP/image, 크기별 sensitivity, 장비/기관별 subgroup을 함께 봅니다. 동일 환자의 frame이 train/validation에 섞이지 않도록 patient-level split을 사용합니다.

6. 실습

def log_shapes(model, x):
    hooks=[]
    for name,m in model.named_modules():
        if name in {"backbone.layer2","backbone.layer3","backbone.layer4"}:
            hooks.append(m.register_forward_hook(
                lambda m,i,o: print(tuple(o.shape))))
    model(x)
    for h in hooks: h.remove()

실제 detector에 hook을 걸어 C3/C4/C5 shape를 기록하고 가장 작은 병변의 pixel size와 비교하세요.

7. Debugging checklist

annotation 좌표계 → resize/letterbox 변환 → augmentation 후 box → feature stride → positive assignment → NMS 순으로 확인합니다. Detection 실패를 backbone 성능 문제로 단정하기 전에 label transform 오류부터 배제해야 합니다.
