Self-Attention
Q · K · V를 Tensor로 이해하기

Q/K/V를 암기하지 않고 “현재 token이 무엇을 찾는가(Q), 각 token이 무엇을 대표하는가(K), 실제 전달할 정보가 무엇인가(V)”라는 관점에서 matrix multiplication과 shape를 추적합니다.

1. 기본 수식

Q = X Wq
K = X Wk
V = X Wv

Attention(Q,K,V) = softmax(Q Kᵀ / sqrt(d_k)) V

입력 X가 [B,N,D]라면 N은 token 수, D는 embedding dimension입니다. Q와 K의 내적은 token-to-token 유사도 행렬 [B,N,N]을 만듭니다.

2. 왜 sqrt(d_k)로 나누나?

d가 커질수록 dot product의 분산도 커져 softmax가 지나치게 뾰족해질 수 있습니다. sqrt(d_k) scaling은 logit scale을 안정화하여 gradient가 지나치게 작아지는 문제를 완화합니다.

3. Shape walkthrough

X  : [B, 196, 768]
Q  : [B, 196, 768]
K  : [B, 196, 768]
V  : [B, 196, 768]

Q @ K.transpose(-2,-1)
   : [B,196,196]

A @ V
   : [B,196,768]

4. Multi-Head Attention

768차원을 예를 들어 12개의 head로 나누면 head당 64차원입니다. 각 head가 서로 다른 관계를 학습할 수 있고 마지막에 concatenate합니다.

[B,N,768]
→ reshape [B,N,12,64]
→ transpose [B,12,N,64]
→ attention per head
→ concat → [B,N,768]

5. PyTorch 직접 구현

def attention(q, k, v):
    d = q.shape[-1]
    score = q @ k.transpose(-2, -1) / (d ** 0.5)
    weight = score.softmax(dim=-1)
    return weight @ v, weight

translation-friendly inductive biascontent-dependent interaction

7. Ultrasound 관점

병변 내부와 posterior acoustic region처럼 공간적으로 떨어진 영역의 관계를 학습할 수 있다는 점은 attention의 장점입니다. 하지만 고해상도 초음파를 작은 patch로 쪼개면 N이 커져 N² attention memory가 급증합니다. 따라서 patch size, window attention, hybrid CNN-Transformer의 trade-off가 중요합니다.

8. 실습

B, N, D = 2, 196, 768
x = torch.randn(B, N, D)
q = x @ torch.randn(D, D)
k = x @ torch.randn(D, D)
v = x @ torch.randn(D, D)
y, a = attention(q, k, v)
print(a.shape) # [2,196,196]
print(y.shape) # [2,196,768]
print(a.sum(-1)[0,:5]) # 각 query의 attention 합 ≈ 1
