2026.09.15#12Fine-tuning

Fine-tuning Strategy
Freeze → Unfreeze → Discriminative LR

Pretrained backbone을 가져오는 것과 제대로 fine-tune하는 것은 다릅니다. 어떤 layer를 언제 풀고, learning rate를 어떻게 분리하며, checkpoint와 normalization을 어떻게 다룰지 설계합니다.

1. Freeze는 무엇을 의미하나?

for p in model.backbone.parameters():
    p.requires_grad = False

해당 parameter에 대한 gradient 계산과 update를 막습니다. 하지만 BatchNorm의 running mean/variance 같은 buffer 동작은 별도 문제이므로 requires_grad=False만으로 모든 상태가 고정되는 것은 아닙니다.

2. 언제 head-only 학습부터 시작할까?

새 head가 random initialization이고 dataset이 작다면 pretrained backbone을 먼저 고정해 head를 안정화하는 전략이 유용합니다. 이후 backbone의 뒤쪽 stage부터 점진적으로 풉니다.

3. Progressive unfreezing

# phase 1: head only
freeze(model.backbone)
train(epochs=3)

# phase 2: last stage
unfreeze(model.backbone.layer4)
train(epochs=5)

# phase 3: full fine-tune
unfreeze(model.backbone)
train(epochs=10)

항상 이 순서가 최선인 것은 아닙니다. source와 target domain이 크게 다르면 더 많은 backbone adaptation이 필요할 수 있습니다.

4. Discriminative Learning Rate

optimizer = torch.optim.AdamW([
 {'params': model.backbone.layer1.parameters(), 'lr': 1e-5},
 {'params': model.backbone.layer4.parameters(), 'lr': 5e-5},
 {'params': model.head.parameters(), 'lr': 1e-4},
], weight_decay=1e-4)

early layer는 일반적인 edge/texture representation을 많이 가지고 있으므로 작게 업데이트하고, task-specific head는 더 크게 업데이트하는 아이디어입니다.

5. BatchNorm은 별도로 생각한다

작은 ultrasound batch에서 pretrained BN 통계를 그대로 업데이트하면 불안정해질 수 있습니다. backbone weight freeze 여부와 BN train/eval 상태를 분리해서 실험해야 합니다. 작은 batch에서는 Frozen BN 또는 GroupNorm이 더 안정적인지 비교할 가치가 있습니다.

6. Checkpoint migration

msg = model.load_state_dict(ckpt, strict=False)
print('missing:', msg.missing_keys)
print('unexpected:', msg.unexpected_keys)

strict=False는 문제를 해결하는 마법 옵션이 아닙니다. 새 head 때문에 생긴 missing key인지, backbone 구조를 실수로 변경해서 생긴 것인지 반드시 key를 검토해야 합니다.

7. Ultrasound domain shift

ImageNet 자연영상에서 학습한 backbone을 grayscale ultrasound에 적용할 때 texture statistics와 speckle 특성이 다릅니다. 단순히 pretrained가 항상 우월하다고 가정하지 말고, grayscale channel 처리, normalization, early-layer adaptation을 validation experiment로 확인합니다.

8. 실습

  1. 동일 모델로 head-only / layer4+head / full fine-tune 세 실험을 구성합니다.
  2. 각 phase의 trainable parameter 수를 출력합니다.
  3. layer1/layer4/head의 gradient norm과 ΔW/W를 비교합니다.
  4. BN train/eval 조합을 기록합니다.
  5. validation sensitivity와 overfitting gap을 비교합니다.

9. 복습 문제

  1. freeze와 model.eval()은 같은가? 아니다.
  2. 왜 head LR을 더 크게 줄 수 있는가? 새 task에 맞게 처음부터 학습해야 하기 때문이다.
  3. strict=False 후 무엇을 확인해야 하나? missing/unexpected keys.
  4. 작은 batch에서 BN이 왜 문제인가? batch statistics 추정이 불안정할 수 있다.
  5. domain shift가 크면 early backbone도 조정해야 하는가? 가능성이 있으므로 실험으로 판단한다.
