💡 Senior AI Engineer의 시각
Convolution이 국소적 윈도우(Local Receptive Field)에 고정된 연산이라면, Self-Attention은 "입력 데이터 자신에 의해 실시간으로 동적 가중치가 결정되는 완전 연결 그래프(Dynamic Fully Connected Graph)"입니다. 이 유연성은 시각적 장거리 상호작용(Long-range Dependency)을 가능케 하지만, $O(S^2)$ 공간 복잡도로 인해 고해상도 의료 영상에서 치명적인 VRAM 폭발을 유발합니다.

1. 학습 목표 및 핵심 용어 정의

  • Query, Key, Value의 정보 검색(Information Retrieval) 메타포와 행렬 투영의 기하학적 의미를 설명할 수 있습니다.
  • 내적 스케일링 계수 $\frac{1}{\sqrt{d_k}}$가 Softmax의 기울기 소실(Gradient Vanishing)을 방지하는 수학적 원리를 증명합니다.
  • Multi-Head Attention에서 [B, S, D] 텐서가 여러 헤드로 쪼개지고 다시 병합되는 전 과정을 1차원 메모리 스트라이드 관점에서 추적합니다.
  • 시퀀스 길이 $S$가 증가할 때 어텐션 맵 텐서가 점유하는 메모리 크기를 바이트 단위로 정밀하게 산출할 수 있습니다.

2. Q, K, V 텐서 사상의 기하학적 의미

입력 텐서 $X \in \mathbb{R}^{B \times S \times D}$ (Batch, Sequence Length, Embedding Dimension)가 주어졌을 때, 3개의 독립적인 학습 가능한 가중치 행렬 $W_Q, W_K, W_V \in \mathbb{R}^{D \times D}$를 통해 선형 투영됩니다.

$$Q = X W_Q, \quad K = X W_K, \quad V = X W_V \quad \in \mathbb{R}^{B \times S \times D}$$

각 토큰 벡터는 고정된 하나의 벡터로 남아있지 않고, "어떤 정보를 요구하는가(Query)", "남들에게 어떤 키로 식별되는가(Key)", "실제 전달할 의미가 무엇인가(Value)"의 3가지 역할로 분기됩니다.

3. Scaled Dot-Product: 왜 $\sqrt{d_k}$로 나누는가?

수학적 증명: Softmax Gradient Saturation 방지
Query 벡터 $q$와 Key 벡터 $k$의 각 원소 $q_i, k_i$가 평균 0, 분산 1인 독립동일분포(i.i.d.)를 따른다고 가정합시다.
두 벡터의 내적 $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$의 기댓값과 분산은 다음과 같습니다.
$$\mathbb{E}[q \cdot k] = \sum_{i=1}^{d_k} \mathbb{E}[q_i] \mathbb{E}[k_i] = 0$$$$\text{Var}(q \cdot k) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = \sum_{i=1}^{d_k} \text{Var}(q_i) \text{Var}(k_i) = d_k$$
즉, 차원 $d_k$가 커질수록(예: $d_k=64$일 때 표준편차 $\sqrt{64}=8$) 내적값의 크기가 극단적으로 벌어집니다.
이를 그대로 Softmax 함수에 통과시키면 가장 큰 원소의 확률은 1에 수렴하고 나머지는 0에 수렴하여, Softmax의 기울기(Gradient)가 0으로 포화(Vanishing)되어 가중치가 학습되지 않습니다.
따라서 표준편차인 $\sqrt{d_k}$로 나누어 분산을 1로 정규화하는 것입니다.
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

5. $O(S^2)$ 연산 복잡도와 VRAM Footprint 분석

입력 토큰 수 $S$에 대해 $QK^T$ 연산의 어텐션 맵 텐서 크기는 다음과 같습니다.

$$\text{Memory}_{\text{AttnMap}} = B \times \text{num\_heads} \times S \times S \times \text{Bytes per Element}$$
입력 패치 크기토큰 시퀀스 길이 $S$ ($H \times W$)헤드 수 (h)FP32 기준 어텐션 맵 VRAM (B=8)
$16 \times 16$ 패치 ($256 \times 256$ 영상)$16 \times 16 = \mathbf{256}$8$8 \times 8 \times 256^2 \times 4 \text{ B} = \mathbf{16.8 \text{ MB}}$
$16 \times 16$ 패치 ($512 \times 512$ 영상)$32 \times 32 = \mathbf{1,024}$8$8 \times 8 \times 1024^2 \times 4 \text{ B} = \mathbf{268.4 \text{ MB}}$
$16 \times 16$ 패치 ($1024 \times 1024$ 영상)$64 \times 64 = \mathbf{4,096}$8$8 \times 8 \times 4096^2 \times 4 \text{ B} = \mathbf{4.29 \text{ GB}}$

해상도가 4배($256 \rightarrow 1024$) 증가할 때 어텐션 맵 단일 텐서 크기는 256배 폭증합니다. 12개 인코더 레이어를 고려하면 순수 어텐션 맵만으로 50GB 이상의 VRAM이 요구되어 즉각적인 OOM(Out of Memory)이 발생합니다.

6. 의료 초음파: 전역 문맥(Global Context)과 국소 음영

초음파 진단에서 전문의는 특정 결절(Nodule) 하나만 보지 않고, 주변 정상 유선 조직, 흉근(Pectoralis Muscle), 그리고 결절 하단의 **후방 음향 증강(Posterior Enhancement) 또는 음영(Shadowing)**을 종합하여 양/악성을 판단합니다.

  • CNN의 한계: 국소 수용 영역(Local Receptive Field)에 갇혀 있어, 50mm 아래의 음향 그림자와 얕은 부위의 종양 간의 상관관계를 초기 레이어에서 직접 연결하지 못합니다.
  • Self-Attention의 장점: 공간적 거리에 구애받지 않고 단 1회의 연산만으로 종양 영역과 후방 음영 영역 간의 높은 어텐션 가중치($A_{ij}$)를 형성하여 악성 침윤 여부를 정확하게 추론합니다.
  • 실무 해결책: 고해상도 VRAM 한계를 극복하기 위해 전체 $1024 \times 1024$에 전역 어텐션을 적용하지 않고, Window Attention (Swin Transformer)이나 Axial Attention을 채택하는 것이 표준 실무 패턴입니다.

7. PyTorch 실전 MultiHeadAttention 구현

import math
import torch
import torch.nn as nn

class CustomMultiHeadAttention(nn.Module):
    def __init__(self, embed_dim=256, num_heads=8):
        super().__init__()
        assert embed_dim % num_heads == 0, "embed_dim은 num_heads로 나누어 떨어져야 합니다."
        self.embed_dim = embed_dim
        self.num_heads = num_heads
        self.head_dim = embed_dim // num_heads
        self.scale = 1.0 / math.sqrt(self.head_dim)
        
        # 3개 projection을 단일 행렬로 통합하여 연산 효율 극대화
        self.qkv_proj = nn.Linear(embed_dim, embed_dim * 3, bias=True)
        self.out_proj = nn.Linear(embed_dim, embed_dim, bias=True)

    def forward(self, x):
        B, S, D = x.shape
        
        # 1. Linear Projection 및 Q, K, V 분리: [B, S, 3 * D]
        qkv = self.qkv_proj(x)
        # Reshape to [B, S, 3, num_heads, head_dim] -> Permute to [3, B, num_heads, S, head_dim]
        qkv = qkv.reshape(B, S, 3, self.num_heads, self.head_dim).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]
        
        # 2. Scaled Dot-Product: q @ k.transpose(-2, -1) -> [B, num_heads, S, S]
        attn_scores = torch.matmul(q, k.transpose(-2, -1)) * self.scale
        attn_weights = torch.softmax(attn_scores, dim=-1)
        
        # 3. Value와의 가중합: [B, num_heads, S, head_dim]
        out = torch.matmul(attn_weights, v)
        
        # 4. 헤드 병합 및 최종 Projection: [B, S, D]
        out = out.permute(0, 2, 1, 3).contiguous().reshape(B, S, D)
        return self.out_proj(out), attn_weights

if __name__ == "__main__":
    # 초음파 토큰 시뮬레이션: B=4, 16x16 패치 토큰(S=256), D=256
    mha = CustomMultiHeadAttention(embed_dim=256, num_heads=8)
    sample_tokens = torch.randn(4, 256, 256)
    
    out, weights = mha(sample_tokens)
    print(f"출력 텐서 Shape: {out.shape}")
    print(f"주의집중 맵 Shape: {weights.shape}")
    assert out.shape == (4, 256, 256)
    assert weights.shape == (4, 8, 256, 256)

8. 복습 퀴즈 및 상세 해설

  1. Q1. Scaled Dot-Product Attention 수식에서 $QK^T$를 $\sqrt{d_k}$로 나누는 근본적인 수학적 이유는 무엇인가?
    정답 및 해설: $d_k$가 커질수록 두 벡터 내적의 분산이 $d_k$에 비례하여 증가하므로, Softmax 함수의 극단적인 영역으로 입력이 치우쳐 기울기가 0으로 포화(Gradient Vanishing)되는 현상을 방지하기 위해 분산을 1로 정규화하는 것입니다.
  2. Q2. Single-Head Attention 대비 Multi-Head Attention이 갖는 아키텍처적 우위는 무엇인가?
    정답 및 해설: 단일 평균 어텐션에 억제되지 않고, 서로 다른 표현 서브스페이스(Subspace)에서 상이한 위치와 문맥(예: 한 헤드는 종양 경계선, 다른 헤드는 후방 음영 영역)을 독립적으로 동시에 포착할 수 있습니다.
  3. Q3. Self-Attention의 시간 및 공간 복잡도가 토큰 시퀀스 길이 $S$에 대해 $O(S^2)$가 되는 연산 단계는 어디인가?
    정답 및 해설: $Q \in \mathbb{R}^{S \times d_k}$와 $K^T \in \mathbb{R}^{d_k \times S}$의 행렬곱을 통해 모든 토큰 쌍 간의 유사도를 담는 $S \times S$ 크기의 어텐션 맵(Attention Map)을 생성하는 단계입니다.
  4. Q4. $1024 \times 1024$ 고해상도 초음파 영상에 $16 \times 16$ 패치 전역 어텐션을 적용할 때 발생하는 실무적 문제는?
    정답 및 해설: 시퀀스 길이가 $S = 64 \times 64 = 4,096$으로 급증하여 단일 레이어의 어텐션 맵만으로 수 GB의 VRAM을 소모하므로, GPU 메모리 부족(OOM)으로 모델 학습이 불가능해집니다.
  5. Q5. CNN과 비교했을 때 Self-Attention이 초음파 영상 내 병변과 원거리 아티팩트(후방 음영 등)의 상호작용을 포착하는 데 유리한 이유는?
    정답 및 해설: 공간적 거리에 따라 Receptive Field가 점진적으로 누적되어야 하는 CNN과 달리, Self-Attention은 단 1회의 연산으로 영상 내 임의의 두 원거리 픽셀 간의 가중치를 직접 연결(Direct Short-path)할 수 있기 때문입니다.
