AI 전문 개발 학습 #01 — Neural Network를 Tensor 관점에서 해부하기

Tensor shape 변화, Conv2d의 channel·parameter·출력 크기, CNN의 feature 추출 과정을 코드와 실습으로 이해합니다.

예상 학습시간: 40~50분

1. 이번 회차 목표

CNN을 아래처럼 보는 습관을 버리는 것이 첫 번째 목표입니다.

Image → Conv → ReLU → Conv → Output

대신 이렇게 봐야 합니다.

Tensor → Shape 변화 → 수치 연산 → Feature 추출 → Parameter 학습 → Tensor

예를 들어 초음파 영상이 있다고 합시다.

x.shape

## torch.Size([8, 1, 256, 256])

각 숫자는:

8   = Batch
1   = Channel
256 = Height
256 = Width

즉,

[B, C, H, W]

입니다.

2. Conv2d를 실제로 이해하기

다음 코드를 자주 사용했을 것입니다.

conv = nn.Conv2d(
    in_channels=1,
    out_channels=32,
    kernel_size=3,
    stride=1,
    padding=1
)

입력이

[8, 1, 256, 256]

이면 출력은

[8, 32, 256, 256]

입니다.

중요한 질문은:

왜 channel이 1 → 32가 되었는가?

입니다.

Conv layer에는 32개의 filter가 있습니다.

각 filter가 서로 다른 특징을 학습합니다.

Input
  │
  ├─ Filter #1 → Feature map #1
  ├─ Filter #2 → Feature map #2
  ├─ Filter #3 → Feature map #3
  │
  ...
  └─ Filter #32 → Feature map #32

따라서 출력 channel은 feature의 종류 수라고 이해할 수 있습니다.

3. Parameter 개수 계산

위 Conv의 weight shape은:

[32, 1, 3, 3]

따라서 weight:

32 × 1 × 3 × 3
= 288

bias가 있다면:

32

총 parameter:

320

입니다.

이 계산을 직접 할 수 있어야 모델 구조를 제대로 분석할 수 있습니다.

4. Tensor 크기가 줄어드는 원리

Conv 출력 크기는 다음 관계로 결정됩니다.

Hout = floor((H + 2P - D(K-1) - 1) / S + 1)

간단한 경우 dilation=1이면:

Hout = floor((H + 2P - K) / S + 1)

예를 들어:

Input = 256
Kernel = 3
Padding = 1
Stride = 2

이면:

(256 + 2 - 3) / 2 + 1
≈ 128

따라서:

[B, 32, 256, 256]

↓ stride=2

[B, 64, 128, 128]

처럼 spatial resolution이 절반으로 감소합니다.

5. CNN을 보는 새로운 방법

예를 들어:

self.encoder = nn.Sequential(
    nn.Conv2d(1, 32, 3, 1, 1),
    nn.ReLU(),

    nn.Conv2d(32, 64, 3, 2, 1),
    nn.ReLU(),

    nn.Conv2d(64, 128, 3, 2, 1),
    nn.ReLU()
)

이걸 보면 머릿속에서 즉시 다음이 나와야 합니다.

Input
[1,256,256]

 ↓ Conv

[32,256,256]

 ↓ Downsampling

[64,128,128]

 ↓ Downsampling

[128,64,64]

즉 모델 코드를 읽을 때 tensor flow를 동시에 머릿속에서 그리는 능력이 중요합니다.

6. Ultrasound AI에 적용

예를 들어 breast ultrasound lesion detection을 생각해봅시다.

초기 layer는 보통 비교적 low-level feature를 추출합니다.

edge
texture
boundary
speckle pattern

깊어질수록:

mass-like pattern
shape
posterior acoustic feature
lesion context

같은 보다 추상적인 feature representation을 학습하게 됩니다.

따라서 단순히

Conv가 많으면 좋은 모델

이 아닙니다.

중요한 것은:

어느 spatial resolution에서 어떤 feature를 보존하고 있는가?

입니다.

작은 병변 detection에서는 특히 중요합니다.

너무 빠르게

256
→128
→64
→32
→16

으로 downsampling하면 작은 lesion 정보가 사라질 수 있기 때문입니다.

7. 첫 번째 실습

다음 모델의 shape을 코드 실행 전에 계산해 보십시오.

model = nn.Sequential(
    nn.Conv2d(1, 16, 3, 2, 1),
    nn.ReLU(),

    nn.Conv2d(16, 32, 3, 2, 1),
    nn.ReLU(),

    nn.Conv2d(32, 64, 3, 2, 1)
)

입력:

[4, 1, 256, 256]

정답:

[4,1,256,256]

↓
[4,16,128,128]

↓
[4,32,64,64]

↓
[4,64,32,32]

이 정도 계산은 앞으로 모델 코드를 보는 순간 자동으로 되어야 합니다.
