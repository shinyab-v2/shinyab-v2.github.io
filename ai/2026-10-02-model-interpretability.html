2. Grad-CAM — Full name과 의미

Grad-CAM: Grad-CAM은 Gradient-weighted Class Activation Mapping의 약자입니다. 특정 class score의 gradient를 convolution feature map에 가중해 공간적 중요도 heatmap을 만듭니다.

구체적 예시

병변 분류가 맞더라도 heatmap이 병변이 아닌 화면 문자나 측정 marker에 집중한다면 shortcut learning을 의심할 수 있습니다.

3. Saliency Map — Full name과 의미

Saliency Map: Saliency Map은 출력 score가 입력 pixel 변화에 얼마나 민감한지 gradient 등으로 시각화하는 방법의 총칭입니다.

구체적 예시

밝은 영역이 임상적 인과관계를 증명하는 것은 아닙니다. 모델 민감도에 대한 단서로 사용합니다.

4. Shortcut Learning — Full name과 의미

Shortcut Learning: Shortcut Learning은 본질적 병변 특징 대신 데이터셋의 우연한 단서를 이용해 예측하는 현상입니다.

구체적 예시
