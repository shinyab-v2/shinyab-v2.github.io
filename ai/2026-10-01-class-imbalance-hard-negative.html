2. Class Imbalance — Full name과 의미

Class Imbalance: Class Imbalance(클래스 불균형)는 positive와 negative 샘플 수가 크게 다른 상태입니다.

구체적 예시

100,000개의 background location과 200개의 lesion-positive location이 있으면 쉬운 negative가 loss를 지배할 수 있습니다.

3. Focal Loss — Full name과 의미

Focal Loss: Focal Loss는 쉬운 샘플의 loss 기여도를 줄여 어려운 샘플에 더 집중하도록 만든 손실 함수입니다. 대표 형태는 -(1-p_t)^γ log(p_t)입니다.

구체적 예시

p_t=0.99인 쉬운 정답은 γ=2일 때 가중치가 0.0001 수준이지만 p_t=0.6이면 0.16이 되어 상대적으로 더 크게 학습됩니다.

4. Hard Negative Mining — Full name과 의미

Hard Negative Mining: Hard Negative Mining은 모델이 자주 오인하는 negative를 선택해 학습에 더 적극적으로 사용하는 방법입니다.

구체적 예시

초음파 shadow나 nipple artifact를 lesion으로 반복 검출한다면 해당 FP를 수집해 hard-negative pool을 구성합니다.
