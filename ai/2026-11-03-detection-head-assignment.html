💡 Senior AI Engineer의 시각
"검출 모델 성능의 70%는 Backbone이 아니라 **라벨 할당(Label Assignment)**에서 결정된다"는 것이 현대 객체 검출의 정설입니다. 수만 개의 앵커 중 어떤 그리드를 Positive(양성 학습 대상)로 지정할 것인가의 기준이 모델의 수렴 속도와 위양성(False Positive) 억제력을 좌우합니다. 특히 형태가 불규칙한 초음파 종양 검출에서는 고정 IoU 룰 대신 동적 할당(Dynamic Assignment)이 필수적입니다.

1. 학습 목표 및 핵심 용어 정의

  • Decoupled Head 구조에서 분류(Classification)와 박스 회귀(Regression) 피처 간의 상호 충돌(Feature Conflict) 문제를 규명합니다.
  • Anchor-based 방식과 Anchor-free 방식의 본질적인 수학적 차이가 앵커의 유무가 아니라 **"Positive 샘플의 정의 방식"**에 있음을 이해합니다.
  • ATSS (Adaptive Training Sample Selection)의 통계적 임계값 산출과 SimOTA (Optimal Transport Assignment)의 최적 수송 비용 행렬을 수학적으로 증명합니다.
  • 초음파 병변의 흐릿한 경계(Acoustic Shadowing 등)를 다루기 위한 Centerness 및 Quality-aware Loss 전략을 설계할 수 있습니다.

2. Detection Head: Decoupled Head vs Coupled Head

과거 YOLOv3나 RetinaNet은 단일 Conv 레이어에서 분류 로짓($C$개)과 박스 좌표(4개)를 동시에 출력하는 Coupled Head를 사용했습니다. 그러나 분류 태스크는 변환 불변성(Translation Invariance)을 선호하고, 회귀 태스크는 변환 등변성(Translation Equivariance)을 요구하므로 피처 간 상호 충돌이 발생합니다.

3. Anchor-based vs Anchor-free: 진짜 차이는 무엇인가?

Zhang et al. (CVPR 2020, ATSS) 연구진은 Anchor-based(RetinaNet)와 Anchor-free(FCOS)의 성능 차이를 체계적으로 분석하여 충격적인 결론을 도출했습니다.

"성능 격차의 본질은 박스를 타일링하느냐 점을 찍느냐의 회귀 방식이 아니라, 어떤 샘플을 Positive/Negative로 선택하는가의 Label Assignment 규칙에 있었다."

두 방식의 회귀 타깃 표현식은 완벽히 동치(Isomorphic)로 변환될 수 있습니다.

$$\text{Anchor-free}: (l, t, r, b) \quad \Longleftrightarrow \quad \text{Anchor-based}: (\Delta x, \Delta y, \Delta w, \Delta h)$$

4. Label Assignment의 진화 (IoU Rule → ATSS → SimOTA)

1) 정적 임계값 방식의 한계

과거 방식은 "Anchor와 GT 간의 $\text{IoU} > 0.5$이면 Positive, $< 0.4$이면 Negative"라는 고정 룰을 썼습니다. 그러나 극소 병변이나 가로세로 비율이 극단적인 종양의 경우 $\text{IoU} > 0.5$를 만족하는 앵커가 단 1개도 존재하지 않아 GT가 학습에서 누락되는 치명적인 결함이 발생합니다.

2) ATSS (Adaptive Training Sample Selection)

각 Ground Truth(GT)에 대해 피라미드 레벨마다 중심이 가장 가까운 $k$개 후보(총 $k \times L$개)를 선택한 뒤, 해당 후보들의 IoU 평균($m$)과 표준편차($g$)를 계산하여 동적 임계값을 산출합니다.

$$t = m + g$$$$\text{Positive if } \text{IoU}(A_i, GT) \ge t \quad \text{and Center}(A_i) \in GT$$

5. SimOTA (최적 수송 문제)의 수학적 원리

YOLOX에서 도입된 **SimOTA (Simplified Optimal Transport Assignment)**는 라벨 할당을 수송 문제(Optimal Transport)로 모델링합니다. 즉, 각 GT는 일정량의 라벨 공급자(Supplier)이고, 각 Anchor/Grid는 라벨 수요자(Demander)입니다.

비용 함수 (Matching Cost)

GT $i$와 예측 후보 $j$ 사이의 할당 비용 $c_{ij}$는 분류 손실과 위치 회귀 손실의 가중 합으로 정의됩니다.

$$c_{ij} = L_{ij}^{\text{cls}} + \lambda_{\text{reg}} L_{ij}^{\text{reg}} + \lambda_{\text{center}} L_{ij}^{\text{center}}$$
  • Dynamic $k$ 결정: 각 GT $i$에 대해 전체 앵커들과의 IoU 상위 10개를 더하여, 해당 GT가 소유할 Positive 개수 $k_i = \max\left(1, \sum_{j \in \text{Top10}} \text{IoU}_{ij}\right)$를 동적으로 결정합니다.
  • Global Cost 최소화: 각 GT는 비용 $c_{ij}$가 가장 작은 $k_i$개의 앵커에만 라벨을 할당합니다. 단일 앵커가 여러 GT와 경합할 경우, 비용이 더 작은 GT에 독점 배정됩니다.

6. 의료 초음파: 모호한 종양 경계와 Centerness

유방 초음파의 악성 침윤성 암(Invasive Ductal Carcinoma)은 경계가 침상형(Spiculated)이거나 각진(Angular) 형태를 띠며, 후방 음향 음영(Acoustic Shadow)으로 인해 어디까지가 종양인지 경계 픽셀이 모호합니다.

  • Centerness의 역할: FCOS 및 modern head는 그리드 위치 $(x, y)$에서 좌/우/상/하 거리 $(l, r, t, b)$를 기반으로 다음 중심도(Centerness)를 회귀합니다.
$$\text{Centerness}^* = \sqrt{\frac{\min(l, r)}{\max(l, r)} \times \frac{\min(t, b)}{\max(t, b)}}$$

초음파 영상의 모호한 외곽 경계에서 생성된 불확실한 예측은 Centerness 점수가 0에 가깝게 낮아져, NMS(Non-Maximum Suppression) 단계에서 점수 곱($\text{Score} = \text{ClsScore} \times \text{Centerness}$)에 의해 위양성(False Positive)으로 자동 필터링됩니다.

7. PyTorch 실전 Dynamic Assignment 구현

import torch
import torch.nn.functional as F

def simota_dynamic_assign(cost_matrix: torch.Tensor, pair_wise_ious: torch.Tensor):
    """
    cost_matrix: [num_gt, num_candidates] (비용 행렬, 작을수록 좋은 매칭)
    pair_wise_ious: [num_gt, num_candidates] (GT와 후보 간 IoU)
    반환: matched_gt_inds: [num_candidates] (-1은 Background, 0 이상은 할당된 GT 인덱스)
    """
    num_gt, num_candidates = cost_matrix.shape
    
    # 1. 각 GT별 dynamic k 추정 (상위 10개 IoU의 합)
    topk_ious, _ = torch.topk(pair_wise_ious, k=min(10, num_candidates), dim=1)
    dynamic_k = torch.clamp(topk_ious.sum(dim=1).int(), min=1)
    
    # 2. GT별로 비용이 가장 낮은 dynamic_k 개의 후보 선택 (Masking)
    matching_matrix = torch.zeros_like(cost_matrix)
    for gt_idx in range(num_gt):
        k = dynamic_k[gt_idx].item()
        _, pos_idx = torch.topk(cost_matrix[gt_idx], k=k, largest=False)
        matching_matrix[gt_idx, pos_idx] = 1.0
        
    # 3. 단일 후보 앵커가 2개 이상의 GT에 중복 배정된 경우 (Conflict Resolution)
    # 비용이 더 작은 GT에 우선 배정
    candidate_assigned_counts = matching_matrix.sum(dim=0)
    if (candidate_assigned_counts > 1).sum() > 0:
        dup_mask = candidate_assigned_counts > 1
        for cand_idx in torch.where(dup_mask)[0]:
            assigned_gts = torch.where(matching_matrix[:, cand_idx] > 0)[0]
            best_gt = assigned_gts[torch.argmin(cost_matrix[assigned_gts, cand_idx])]
            matching_matrix[:, cand_idx] = 0.0
            matching_matrix[best_gt, cand_idx] = 1.0
            
    # 최종 결과: 각 후보별 매칭된 GT 인덱스 (-1: 배경)
    matched_gt_inds = torch.full((num_candidates,), -1, dtype=torch.long)
    pos_cand_mask = matching_matrix.sum(dim=0) > 0
    matched_gt_inds[pos_cand_mask] = torch.argmax(matching_matrix[:, pos_cand_mask], dim=0)
    
    return matched_gt_inds

if __name__ == "__main__":
    # 2개의 초음파 병변 GT와 100개의 앵커 후보 시뮬레이션
    torch.manual_seed(42)
    fake_cost = torch.rand(2, 100) # 비용 행렬
    fake_ious = torch.rand(2, 100) * 0.8 # IoU 행렬
    
    matched = simota_dynamic_assign(fake_cost, fake_ious)
    pos_count = (matched >= 0).sum().item()
    print(f"총 후보 100개 중 동적 Positive 할당 개수: {pos_count}개")
    print(f"GT 0번에 할당된 개수: {(matched == 0).sum().item()}개")
    print(f"GT 1번에 할당된 개수: {(matched == 1).sum().item()}개")

8. 복습 퀴즈 및 상세 해설

  1. Q1. Detection Head에서 Decoupled Head(분리형 헤드)를 적용하는 주된 이론적 이유는 무엇인가?
    정답 및 해설: 객체 분류는 공간적 이동에 둔감한 '변환 불변성(Translation Invariance)'을 필요로 하지만, 바운딩 박스 위치 회귀는 이동에 민감한 '변환 등변성(Translation Equivariance)'을 필요로 하므로 두 태스크 간의 피처 충돌을 방지하기 위함입니다.
  2. Q2. ATSS 논문에서 밝혀낸 Anchor-based와 Anchor-free 모델 간의 성능 차이를 결정짓는 핵심 요인은?
    정답 및 해설: 앵커 박스 유무나 좌표 회귀 방식이 아니라, 어떤 위치를 훈련 대상(Positive)으로 선정하는가의 **Label Assignment(라벨 할당)** 규칙입니다.
  3. Q3. 기존의 고정 Max-IoU 임계값 방식이 작은 크기의 초음파 종양 검출에서 실패하기 쉬운 이유는?
    정답 및 해설: 작은 객체는 해상도 저하로 인해 사전 정의된 고정 앵커 박스와의 최대 IoU가 0.5를 넘지 못하는 경우가 빈번하여, 정답(GT)이 Positive로 할당되지 못하고 학습에서 완전히 누락되기 때문입니다.
  4. Q4. SimOTA에서 각 GT가 소유할 Positive 앵커 개수 $k$를 결정하는 방식은?
    정답 및 해설: 해당 GT와 전체 앵커 간의 상위 10개 IoU 값을 합산하여 정수로 클램핑(최소 1)함으로써, GT의 크기와 예측 품질에 비례하여 적응적으로 $k$를 결정합니다.
  5. Q5. FCOS 계열에서 도입된 Centerness(중심도) 브랜치가 의료 초음파 검출에서 기여하는 실무적 효과는?
    정답 및 해설: 종양 중심에서 벗어난 외곽 경계의 불확실한 예측 박스에 낮은 Centerness 점수를 부여하여, 최종 NMS 단계에서 위양성(False Positive)으로 쉽게 걸러낼 수 있도록 돕습니다.
