Training Loop from Scratch

forward→loss→backward→optimizer step을 한 줄씩 추적

1. 오늘의 목표

forward→loss→backward→optimizer step을 한 줄씩 추적. 이번 회차는 약 40~60분을 기준으로 하며, 개념 설명 뒤 실제 코드와 수치 확인까지 진행합니다.

Forward Pass

Full name / 의미: 순전파

입력 Tensor가 모델 연산을 거쳐 prediction으로 변환되는 과정

Backward Pass

Full name / 의미: 역전파

loss의 미분을 계산 그래프를 따라 parameter까지 전달하는 과정

Gradient Accumulation

Full name / 의미: 그래디언트 누적

여러 mini-batch의 gradient를 누적한 뒤 한 번 optimizer.step()하는 방법

5. 구체적인 Ultrasound AI 예시

GPU 메모리 때문에 batch=2만 가능할 때 4 step을 누적하면 8 sample의 gradient를 모은 뒤 update할 수 있습니다. BatchNorm 동작까지 batch=8과 같아지는 것은 아닙니다.

6. 실제 코드에서 확인

optimizer.zero_grad()
for step, (x,y) in enumerate(loader):
    pred = model(x)
    loss = criterion(pred,y) / 4
    loss.backward()
    if (step+1) % 4 == 0:
        optimizer.step()
        optimizer.zero_grad()

코드를 그대로 실행하는 것보다 각 줄에서 입력/출력 Tensor, parameter 등록 여부, gradient 발생 여부, device와 dtype을 함께 출력해 보는 것이 핵심입니다.

7. 설계 Trade-off

성능 향상이 항상 좋은 변경은 아닙니다. accuracy/sensitivity뿐 아니라 GPU memory, throughput, latency, reproducibility, 작은 병변 subgroup 성능을 함께 기록합니다. 변경 전 baseline을 남기고 한 번에 하나의 주요 변수를 바꿉니다.

8. Debugging 실습

  1. 입력 batch의 shape·dtype·min/max를 기록합니다.
  2. 핵심 layer의 output shape를 hook으로 확인합니다.
  3. loss가 finite인지 확인합니다.
  4. backward 후 grad=None, NaN/Inf, grad norm을 확인합니다.
  5. optimizer.step() 전후 실제 parameter가 변했는지 확인합니다.

정답·해설 방향

1~3번은 위 정의를 단순 암기하지 말고 입력→연산→출력 변화로 설명합니다. 4번은 baseline 대비 한 변수만 변경하고 lesion-size subgroup을 분리합니다. 5번은 data/activation, loss/gradient, 실제 parameter update를 우선 확인합니다.
