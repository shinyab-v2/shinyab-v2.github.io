Vision Transformer(ViT)의 등장은 컴퓨터 비전의 패러다임을 바꿨습니다. 그러나 순수 ViT는 CNN이 본질적으로 가진 **귀납적 편향(Inductive Bias: 지역성 및 이동 불변성)**이 전혀 없기 때문에, 초대규모 데이터셋(JFT-300M 등)으로 사전학습되지 않으면 소규모 의료 영상에서 심각한 과적합(Overfitting)을 겪습니다. 실무 아키텍트는 ViT의 우아한 구조를 이해함과 동시에, 의료 도메인 맞춤형 하이브리드(CNN Stem + ViT) 전략을 구사할 수 있어야 합니다.

1. 학습 목표 및 핵심 용어 정의

  • 2D 이미지를 패치 단위로 분할하여 1차원 임베딩 벡터로 변환하는 수학적 공식과 nn.Conv2d를 활용한 연산 가속 트릭을 규명합니다.
  • 분류 전용 [CLS] 토큰과 1D Positional Embedding이 시퀀스에 결합되는 과정의 텐서 Shape를 추적합니다.
  • Post-LN 대비 Pre-LN (Pre-Layer Normalization) 구조가 깊은 네트워크 학습에서 갖는 수치적 안정성을 설명합니다.
  • 의료 초음파처럼 샘플 수가 제한적인 환경에서 순수 ViT를 성공적으로 적용하기 위한 Hybrid ViT 및 사전학습 전략을 제시합니다.

3. Patchify & Linear Projection: Conv2d 최적화 트릭

수학적으로 패치 분할은 영상을 겹치지 않는 $P \times P$ 크기의 패치로 자른 뒤 $P^2 \cdot C$ 차원의 벡터로 펼치고, 가중치 $E \in \mathbb{R}^{(P^2 \cdot C) \times D}$와 행렬곱하는 과정입니다.

$$x_p \in \mathbb{R}^{N \times (P^2 C)}, \quad z_0 = x_p E \in \mathbb{R}^{N \times D}$$

실제 PyTorch 구현에서는 Python 루프로 영상을 자르지 않고, **커널 크기와 스트라이드가 모두 $P$인 2D Convolution**을 단 1회 실행하여 완벽히 동일한 결과를 하드웨어 가속으로 연산합니다.

# Patchify를 가장 우아하게 구현하는 표준 트릭
proj = nn.Conv2d(in_channels=C, out_channels=D, kernel_size=P, stride=P)
x = proj(img) # [B, D, H/P, W/P]
x = x.flatten(2).transpose(1, 2) # [B, N, D] (N = (H/P) * (W/P))

4. [CLS] Token과 Learnable 1D Positional Embedding

1) [CLS] Token의 역할

특정 패치 하나의 벡터만으로는 전체 영상의 대표성을 갖기 어렵습니다. 따라서 모델 전체의 글로벌 요약자 역할을 수행할 빈(Empty) 토큰 [CLS]($1 \times 1 \times D$)를 학습 가능한 파라미터로 생성하여 시퀀스의 맨 앞에 덧붙입니다.

$$z_0 = \left[ x_{\text{class}}; \; x_p^1 E; \; x_p^2 E; \; \dots; \; x_p^N E \right] \in \mathbb{R}^{B \times (N+1) \times D}$$

2) 1차원 학습 가능 위치 임베딩

Self-Attention은 순서에 불변하므로, 2D 격자 좌표 정보가 없으면 모델은 어느 패치가 왼쪽 위인지 오른쪽 아래인지 모릅니다. ViT는 2D 사인/코사인 좌표 대신 학습 가능한 1D 파라미터 텐서 $E_{\text{pos}} \in \mathbb{R}^{1 \times (N+1) \times D}$를 덧셈합니다.

$$z_0 = z_0 + E_{\text{pos}}$$

5. Pre-LN Transformer Encoder 블록의 수식과 텐서 흐름

오리지널 Attention is All You Need(2017) 논문은 Post-LN($\text{LN}(x + \text{SubLayer}(x))$)을 사용했으나, 이는 깊은 모델에서 그래디언트 폭주를 유발하여 세심한 Warmup 스케줄링이 강제되었습니다. 현대 ViT는 Pre-LN을 표준으로 사용합니다.

$$z_{\ell}' = z_{\ell-1} + \text{MSA}\left(\text{LN}(z_{\ell-1})\right)$$$$z_{\ell} = z_{\ell}' + \text{MLP}\left(\text{LN}(z_{\ell}')\right)$$

Pre-LN은 잔차 연결(Identity Shortcut)의 경로 상에 정규화 레이어가 없어, 입력부터 출력까지 그래디언트가 손실 없이 직접 전파되는 고속도로(Gradient Highway)를 형성합니다.

6. CNN의 Inductive Bias 부재와 소규모 의료 데이터 대책

💡 의료 초음파 실무 권장 아키텍처: Hybrid ViT
수천 장 수준의 환자 초음파 데이터셋에서는 순수 ViT를 바닥부터(From scratch) 학습시키는 것을 피해야 합니다. 초반 1~2개 Stage를 ResNet이나 ConvNeXt의 Stem 블록(Conv + Stride)으로 구성하여 에지/텍스처와 같은 기초 공간 인덕티브 바이어스를 주입한 뒤, 상위 Stage에서만 Transformer 인코더를 결합하는 **하이브리드 아키텍처(Hybrid ViT)**를 채택해야 최고의 민감도(Sensitivity)를 확보할 수 있습니다.

7. PyTorch 완전한 ViT 인코더 소스코드 구현

import torch
import torch.nn as nn

class PatchEmbedding(nn.Module):
    def __init__(self, in_channels=1, patch_size=16, embed_dim=256, img_size=256):
        super().__init__()
        self.num_patches = (img_size // patch_size) ** 2
        # Conv2d를 이용한 우아하고 빠른 패치 프로젝션
        self.proj = nn.Conv2d(in_channels, embed_dim, kernel_size=patch_size, stride=patch_size)

    def forward(self, x):
        # [B, C, H, W] -> [B, D, H/P, W/P] -> [B, N, D]
        x = self.proj(x).flatten(2).transpose(1, 2)
        return x

class ViTEncoderBlock(nn.Module):
    def __init__(self, embed_dim=256, num_heads=8, mlp_ratio=4.0):
        super().__init__()
        self.ln1 = nn.LayerNorm(embed_dim)
        self.attn = nn.MultiheadAttention(embed_dim, num_heads, batch_first=True)
        self.ln2 = nn.LayerNorm(embed_dim)
        mlp_hidden_dim = int(embed_dim * mlp_ratio)
        self.mlp = nn.Sequential(
            nn.Linear(embed_dim, mlp_hidden_dim),
            nn.GELU(),
            nn.Linear(mlp_hidden_dim, embed_dim)
        )

    def forward(self, x):
        # Pre-LN Residual Block
        x = x + self.attn(self.ln1(x), self.ln1(x), self.ln1(x))[0]
        x = x + self.mlp(self.ln2(x))
        return x

class SimpleViT(nn.Module):
    def __init__(self, img_size=256, patch_size=16, in_channels=1, num_classes=2, embed_dim=256, depth=6, num_heads=8):
        super().__init__()
        self.patch_embed = PatchEmbedding(in_channels, patch_size, embed_dim, img_size)
        num_patches = self.patch_embed.num_patches
        
        # [CLS] 토큰 및 Positional Embedding (파라미터 정의)
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.pos_embed = nn.Parameter(torch.randn(1, num_patches + 1, embed_dim) * 0.02)
        
        # 인코더 블록 체인
        self.blocks = nn.ModuleList([ViTEncoderBlock(embed_dim, num_heads) for _ in range(depth)])
        self.norm = nn.LayerNorm(embed_dim)
        self.head = nn.Linear(embed_dim, num_classes)

    def forward(self, x):
        B = x.shape[0]
        x = self.patch_embed(x) # [B, N, D]
        
        # 1. [CLS] 토큰 복제 후 시퀀스 맨 앞에 결합: [B, N + 1, D]
        cls_tokens = self.cls_token.expand(B, -1, -1)
        x = torch.cat((cls_tokens, x), dim=1)
        
        # 2. Positional Embedding 덧셈
        x = x + self.pos_embed
        
        # 3. Transformer Encoder 통과
        for block in self.blocks:
            x = block(x)
        x = self.norm(x)
        
        # 4. [CLS] 토큰의 최종 피처만 추출하여 질환 분류
        cls_out = x[:, 0]
        return self.head(cls_out)

if __name__ == "__main__":
    # 유방 초음파 양성/악성 2분류 모델 시뮬레이션
    model = SimpleViT(img_size=256, patch_size=16, in_channels=1, num_classes=2)
    fake_ultrasound = torch.randn(4, 1, 256, 256) # B=4, C=1, 256x256
    logits = model(fake_ultrasound)
    print(f"출력 로짓 Shape: {logits.shape}")
    assert logits.shape == (4, 2)

8. 복습 퀴즈 및 상세 해설

  1. Q1. $H \times W \times C$ 이미지를 $P \times P$ 크기 패치로 자를 때 생성되는 총 토큰 수 $N$의 계산 공식은?
    정답 및 해설: $N = \frac{H \cdot W}{P^2} = \left(\frac{H}{P}\right) \times \left(\frac{W}{P}\right)$ 입니다.
  2. Q2. Patchify 및 Linear Projection을 단 1회의 PyTorch Conv2d 레이어로 구현할 때 설정해야 하는 kernel_size와 stride의 값은?
    정답 및 해설: kernel_size=P, stride=P 입니다. 패치 크기만큼 건너뛰면서 겹치지 않게 합성곱을 수행하므로 패치 평탄화와 행렬곱이 동시에 완결됩니다.
  3. Q3. Self-Attention 계층에 입력하기 전 [CLS] 토큰을 굳이 맨 앞에 추가하는 이유는?
    정답 및 해설: 특정 개별 패치에 편향되지 않고, 전체 시퀀스에 걸친 모든 패치와의 상호작용 정보를 고르게 집약하여 영상 전체를 대표하는 단일 특징 벡터를 얻기 위함입니다.
  4. Q4. Transformer Encoder에서 Post-LN 대신 Pre-LN 구조가 현대 비전 트랜스포머의 표준이 된 이유는?
    정답 및 해설: 잔차 연결의 주 경로 상에 정규화 레이어가 없어 역전파 시 그래디언트가 손실 없이 흐르는 고속도로(Identity path)가 유지되어, 복잡한 웜업 스케줄링 없이도 심층 모델이 수치적으로 안정하게 수렴하기 때문입니다.
  5. Q5. 대규모 데이터로 사전학습되지 않은 순수 ViT가 수천 장 규모의 의료 초음파 데이터에서 CNN보다 성능이 현저히 떨어지는 근본 원인은?
    정답 및 해설: CNN이 가진 고유한 귀납적 편향(Inductive Bias: 국소성, 이동 불변성)이 없어, 픽셀 간의 기본적인 2차원 공간 기하학 관계를 방대한 데이터로부터 바닥부터 배워야 하므로 심각한 과적합에 빠지기 때문입니다.
