Detection Head & Positive Assignment

FPN/PAN feature가 어떻게 class와 box prediction으로 바뀌는지, 그리고 어떤 prediction을 positive로 학습시킬지 이해합니다.

1. Head가 하는 일

Decoupled head는 classification branch와 regression branch를 분리합니다. 같은 spatial feature를 사용하지만 두 task가 요구하는 표현이 다르기 때문입니다.

feat [B,256,80,80]
cls  -> [B,C,80,80]
box  -> [B,4*R,80,80]   # 구현에 따라 형태가 다름

2. Box regression

좌표를 직접 회귀하거나 cell/anchor를 기준으로 offset·distance distribution을 예측할 수 있습니다. 중요한 것은 decode 전 tensor와 실제 image 좌표를 혼동하지 않는 것입니다.

3. Positive assignment

모든 위치가 정답을 학습하는 것이 아닙니다. GT 주변의 후보 중 geometry, IoU, classification score 등을 이용해 positive를 선택합니다. Assignment가 잘못되면 좋은 backbone이어도 gradient가 잘못된 위치로 전달됩니다.

4. IoU

IoU = intersection area / union area입니다. IoU 계열 loss는 box overlap을 직접 최적화하지만 겹치지 않는 초기 box에서는 gradient 특성이 달라질 수 있어 GIoU/DIoU/CIoU 같은 변형이 사용됩니다.

5. 초음파에서 확인할 것

작은 lesion은 GT box가 몇 픽셀만 이동해도 IoU가 크게 변합니다. annotation uncertainty가 assignment와 regression loss에 미치는 영향을 별도로 실험하세요.

6. 실습

def box_iou(a,b):
    lt=torch.maximum(a[:2],b[:2]); rb=torch.minimum(a[2:],b[2:])
    wh=(rb-lt).clamp(min=0)
    inter=wh.prod()
    area_a=(a[2]-a[0])*(a[3]-a[1])
    area_b=(b[2]-b[0])*(b[3]-b[1])
    return inter/(area_a+area_b-inter+1e-7)

GT box를 ±1, ±2, ±4 pixel 이동시키고 작은/큰 lesion에서 IoU 감소율을 비교해 보세요.
