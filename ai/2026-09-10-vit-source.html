2026.09.10#09ViT Source

Vision Transformer
Image → Patch → Token → Encoder

ViT를 black box로 사용하지 않고 PatchEmbedding이 Conv2d와 어떻게 연결되는지, CLS token과 positional embedding이 shape를 어떻게 바꾸는지 source-code 수준으로 추적합니다.

1. PatchEmbedding = Conv2d로 구현 가능

self.proj = nn.Conv2d(
    in_channels=3,
    out_channels=768,
    kernel_size=16,
    stride=16)

# [B,3,224,224] → [B,768,14,14]
x = self.proj(x)
# → [B,768,196] → [B,196,768]
x = x.flatten(2).transpose(1,2)

kernel=16, stride=16이므로 patch가 겹치지 않습니다. 224/16=14이고 총 token은 14×14=196개입니다.

2. Weight shape

Patch projection Conv의 weight는 [768,3,16,16]입니다. 출력 channel 768개 각각이 RGB 3채널의 16×16 patch 전체를 보고 하나의 embedding component를 만듭니다.

3. CLS token과 positional embedding

cls = self.cls_token.expand(B, -1, -1) # [B,1,768]
x = torch.cat([cls, x], dim=1)         # [B,197,768]
x = x + self.pos_embed                 # [1,197,768] broadcast

Self-attention 자체에는 token 순서 개념이 없기 때문에 positional information을 추가합니다. CLS token은 encoder를 거친 뒤 전체 image representation으로 사용될 수 있습니다.

4. Encoder block

def forward(self, x):
    x = x + self.attn(self.norm1(x))
    x = x + self.mlp(self.norm2(x))
    return x

이 구조는 Pre-Norm Transformer의 전형적인 형태입니다. Residual connection이 attention과 MLP 양쪽에 존재한다는 점을 #05에서 배운 residual gradient 관점과 연결해서 보십시오.

5. MLP 내부 shape

[B,197,768]
→ Linear(768,3072)
→ GELU
→ Dropout
→ Linear(3072,768)
→ [B,197,768]

MLP는 token끼리 섞는 연산이 아니라 각 token의 feature dimension 내부를 변환합니다. token 간 정보 교환은 attention이 담당합니다.

6. Patch size trade-off

Patch224 입력 token 수특징
3249빠르지만 세부정보 손실 큼
16196일반적 균형
8784세밀하지만 attention 비용 급증

기본 global attention의 score matrix는 N×N이므로 patch 16→8은 token이 4배, attention pair는 약 16배가 됩니다.

7. Grayscale ultrasound로 변경

# RGB pretrained
Conv2d(3, 768, 16, 16)
# ultrasound
Conv2d(1, 768, 16, 16)

구조 변경은 쉽지만 pretrained weight shape가 달라집니다. RGB weight를 channel 평균하여 [768,1,16,16]으로 초기화하는 방법 등을 실험할 수 있으며, 단순 shape 호환을 넘어 성능 검증이 필요합니다.

8. Source code 읽는 순서

  1. forward()에서 큰 data flow를 먼저 찾는다.
  2. PatchEmbedding의 입력/출력 shape를 계산한다.
  3. token 추가/reshape/transpose를 표시한다.
  4. Encoder block의 residual 경로를 표시한다.
  5. Attention 내부 Q/K/V shape를 #08과 연결한다.
  6. 마지막 head가 어떤 token을 사용하는지 확인한다.

9. 실습

B = 2
x = torch.randn(B, 1, 256, 256)
proj = nn.Conv2d(1, 384, kernel_size=16, stride=16)
y = proj(x)
print(y.shape)                    # [2,384,16,16]
t = y.flatten(2).transpose(1,2)
print(t.shape)                    # [2,256,384]
